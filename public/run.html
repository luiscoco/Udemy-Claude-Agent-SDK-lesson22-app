01

Prepare the runtime

Use Node.js 24 or later. On Windows the SDK runtime may require Git Bash. The custom server runs inside this app; Open-Meteo needs internet access and the model needs an API account.

node --version
npm --version
02

Install and create your .env file

From presentations, run these commands. Preserve an existing .env and enter your key locally. The npm startup script loads that file; existing shell variables take precedence.

cd .\agent-sdk\lesson22-custom-tools
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the web application

Keep this terminal running and open the printed URL. You do not need to start a separate MCP server. Use Ctrl+C to stop this app.

npm start
# http://127.0.0.1:3122
04

Ask about two cities

Run San Francisco and Madrid. Compare actual handler coordinates, the live temperature and observation time. Weather changes, so there is no fixed expected number.

npm run sample:env -- temperature-sf
npm run sample:env -- temperature-madrid
05

Compare optional hours and wildcard approval

Run omitted hours, explicit six hours and both tools. Inspect the original args and the handler’s applied default. The wildcard pre-approves both weather tools.

npm run sample:env -- rain-default
npm run sample:env -- rain-six
npm run sample:env -- both
06

Wrap a local API and compare permission

Leave the web server running for course-api, which calls /api/course. No pre-approval keeps tools available but denies unresolved calls in this classroom callback.

npm run sample:env -- course-api
npm run sample:env -- no-approval
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3122
# Optional on Windows: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Keep the actual key private. No Managed Agents agent ID or environment ID is required. No duplicate snapshot is included.

Troubleshooting

Use the URL printed by startup. If another app occupies the port, change PORT and restart. If API credit is unavailable, add credit to the account used by this key. Weather HTTP or validation failures remain visible; no cached result replaces a failed live call. The course-api CLI exercise requires this web server to be running on the same PORT.
